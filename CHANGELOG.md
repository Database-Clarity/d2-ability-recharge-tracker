# Changelog

Add a concise, single-line bullet for each notable user-facing change in the same commit as the code change. Keep entries factual and user-relevant; omit internal implementation details. The release workflow publishes only bullets added since the previous release tag. Remove an entry if its change is reverted before release.

- Releases include a self-contained portable Windows ZIP alongside the installer.
- Update checks stay visible beside the page navigation, including startup-check results and retry indicators for network errors.
- The main header is more compact.
- Release notes retain commit history beneath the concise user-facing changelog.
- The in-app changelog focuses on the current release or changes since the previous installed version, with commit history collapsed by default.
- Capture status appears once, in a pill beside the page navigation and a Tracking banner; a closed game shows an amber "Waiting for Destiny 2" notice instead of red errors on every row, and the overlay shows "Waiting for game" instead of "Watching".
- Tracking is decluttered: a segmented **Track: All · Grenade · Melee · Class** selector replaces the per-row "Track only" buttons, area setup moves into an **Areas ▾** menu, and **⋯** holds Move overlay, Copy all results and Troubleshooting.
- A first-run card with **Auto-detect areas…** replaces the empty results table until ability areas are set.
- Copy buttons beside Tracking results appear on hover or keyboard focus, and results get the space of the removed area-size column (area size is in the ability tooltip and Areas menu).
- **Record HUD** and **Open recordings folder** move to Settings › Troubleshooting; while recording, Tracking shows a red recording chip with **Stop**.
- Buttons use clear primary, secondary and link styles; menus use the dark theme; settings section headings are larger.
- The header row is gone: **Pause detection** and a compact **Overlay** switch sit at the bottom of Tracking, and **History** is now a tab.
- Update checks and the changelog move to Settings › About; the main screen only shows an **Update to v…** pill when an update is available, and failed checks no longer appear there.
- Repeat test has a single **Start test** / **Stop test** button that explains inline why it can't start, clearer **Cycles**, **Delay after recharge (s)** and **Hold input for (s)** labels, wrapping status, and a note when the test switches solo tracking (restored afterwards).
- Settings gains a **Shortcuts** section for pause / resume, show / hide overlay and start / stop test, and Capture shows the live measured rate and backend.
- The Display picker leaves Settings; when Destiny 2 isn't found, area selection asks which display to preview in a small dialog.
- The overlay header is slimmer and shows repeat-test progress (for example "Test · Cycle 2/5 · measuring"), recharging rows get a thin progress bar, and ability labels align without padding.
- History uses clearer session verbs (**Make active**, **Add to session**, **Session filter**), and **Add column…** asks for the column name in a small dialog.
- The in-app changelog uses compact, consistent spacing between releases, headings and bullets.
- The selection guide shows one example with practical tips, and explains that a thin margin above and below each area is added automatically.
- History splits into **Sessions** (one session at a time with **New session…**, **Make active** / **End session**, **Rename…**, **Delete…** and its own export) and **All measurements** (every result with a Session column and **Add to session ▾** for any session).
- Custom columns now belong to a session; existing columns are copied to the sessions that use them, and moved results keep their values.
- Deleting a session keeps its measurements as Unsorted, and **Make active** can reopen an ended session.
- Recharge completions are timed from the frame the gray recharge bar disappears, fixing durations that ran up to about 0.7 s long, and quick recasts or use animations no longer drop or shift cycles.
- A recording annotator (`tools/recording-annotator.html`) marks recharge start and end frames in HUD recordings for accuracy checks.
- Recharge starts are found from the start bar itself, even through bright effects or scenery and after use animations; tracking that begins mid-recharge no longer invents or skips cycles and instead shows that cycle as an estimate (marked "estimated", not saved to history); HUD recordings now save their slot areas and skip frozen startup frames.
- **Mark charged** beside Track (global **F9**, rebindable in Settings › Shortcuts) resets tracked abilities and learns their current charged appearance.
- Capture runs at a higher, steadier rate with deadline pacing, accurate presentation timestamps, and recording performance diagnostics.
- The recording annotator is now online at https://database-clarity.github.io/d2-ability-recharge-tracker/annotator/ with editable markers (select, nudge, drag or type a frame) and undo/redo.
- Capture no longer drops to about half the set rate: when a capture tick lands just before the desktop composes a new frame, the tracker briefly waits for that frame instead of skipping to the next tick. HUD recordings keep only newly composed frames (no duplicates).
- The app starts with detection paused; press **Resume detection** (F8) to begin.
- Tracking and Repeat test results no longer flash while measuring.
- Estimated results no longer get cut off: the row shows "± … s (estimated)", and the second line explains the estimate.
- The HUD recording chip no longer stays on "Finishing HUD recording…" after a recording is stopped from Settings, and it sits on its own row instead of under **Mark charged**.
- Repeat test lists every cycle's result as it completes, with a running mean, SD and range, and shows the current cycle's time, progress and prediction.
- Repeat test has its own **Overlay** switch.
- Settings › Troubleshooting › **Recordings folder ▾** can open, change or reset the folder HUD recordings are saved to.
- History groups each repeat test's cycles under its mean row; click the mean's **Result** cell to show or hide them.
- Repeat test can record the HUD for the whole test with its **Record HUD** switch; the recording stops when the test ends.
- Repeat test shows mean, SD and range for both measured and regression totals above the cycle list, and each listed cycle shows its ± uncertainty.
- The whole window now repaints as one image, so live values no longer flicker.
- Fixes v0.1.38's main window flickering as a whole or failing to appear: the whole-window repaint change is reverted.
- Live text (ability rows, Repeat test status, capture status, recording status) no longer flickers: Windows no longer draws it unbuffered each time it changes.
